# مكتبة «استشاري»

مهارات للمساعدات الذكية في إعداد المخرجات المؤسسية والاستشارية العربية.

## المحتوى

| المجلد | ما فيه |
| --- | --- |
| `skills/` | مهارات متخصصة تُجلب عند الحاجة عبر الفهرس `INDEX.md` |
| `core/` | مهارات النواة: الاستشاري التنفيذي، والمراجع المستقل، والكتابة المؤسسية العربية |
| `loader/` | مهارة المحمّل التي تُثبَّت في Claude لتجلب المهارات من هذه المكتبة |

## الاستخدام

- **Claude على الويب والتطبيق:** تُثبَّت مهارات `core/` ومهارة `loader/istishari-library` من إعدادات المهارات. والمحمّل يجلب المهارات المتخصصة عند الحاجة.
- **وكلاء الجهاز (Claude Code وCodex وغيرهما):** تُنسخ المكتبة إلى الجهاز بـ`git clone`، ويُشار الوكيل إلى `INDEX.md` المحلي.

## الإصدارات

الفهرس والمحمّل يشيران إلى إيداع محدد (commit) لا إلى الفرع الرئيس، فلا يصل تعديل إلى الاستخدام إلا بتحديث الرابط في المحمّل. السجل في `CHANGELOG.md`، والإسناد في `NOTICE.md`.
