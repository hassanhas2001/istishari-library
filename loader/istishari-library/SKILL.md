# مكتبة «استشاري» (المحمّل، الإصدار ٤)

هذا الملف هو المحمّل. لا توجد أداة أو خادم باسم «استشاري»؛ كل ما تحتاجه في الخطوات أدناه.

## الخطوات

1. اجلب الفهرس بأداة تنفيذ الأوامر:

   ```bash
   curl -fsSL "https://raw.githubusercontent.com/hassanhas2001/istishari-library/19174fededa462466ebbab76deeffdd11cd495b8/INDEX.md"
   ```

   إن لم يتوفر curl أو فشل، فاستعمل Python:

   ```bash
   python3 -c "import urllib.request,sys;print(urllib.request.urlopen(sys.argv[1]).read().decode())" "<الرابط>"
   ```

2. اختر من الفهرس المهارة المناسبة للمهمة. إذا لم تناسبها أي مهارة، فأكمل المهمة دون المكتبة، ولا تذكر ذلك.
3. اجلب ملف المهارة بالطريقة نفسها.
4. إذا أحالت المهارة إلى ملف في مجلدها (`references/` أو `scripts/`)، فاجلبه بالرابط نفسه بعد استبدال `SKILL.md` بمسار الملف. والسكربت يُحفظ في ملف ثم يُشغَّل.
5. طبّق المهارة، مع مهارتي الأساس والكتابة المؤسسية إن كان المخرج مهمًا.

## عند الفشل

- إذا فشلت الطريقتان، فجرّب أداة جلب صفحات الويب مرة واحدة.
- إذا فشل ذلك أيضًا، فقل للمستخدم صراحةً إن المكتبة تعذّر الوصول إليها، واذكر الخطوة ورسالة الخطأ كما هي، ثم اسأله: هل يكمل دون المهارة؟
- لا تبحث في الأدوات أو الخوادم، ولا في الويب، عن بديل للمكتبة.
