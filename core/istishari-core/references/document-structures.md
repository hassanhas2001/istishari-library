# البنية وعرض المخاطر بحسب نوع الوثيقة

البنية الافتراضية: المحتويات، ثم الملخص، ثم المتن، ثم التوصية. الجدول أدناه يبيّن ما يتغير بحسب النوع. ما يطلبه المستخدم أو تفرضه قوالب جهته مقدَّم عليه.

| نوع الوثيقة | البنية | عرض المخاطر |
| --- | --- | --- |
| مذكرة للمجلس | القرار المطلوب، ثم الخلفية في فقرة، ثم البدائل، ثم التوصية، ثم الأثر المالي، ثم الملاحق. لا محتويات إذا كانت صفحتين أو أقل | فقرة صريحة أو جدول قصير: الخطر ومعالجته |
| خطة استراتيجية | المحتويات، ثم الملخص التنفيذي، ثم التحليل، ثم التوجهات والأهداف، ثم المبادرات، ثم المؤشرات، ثم الحوكمة والمتابعة | سجل مخاطر: الخطر، والاحتمال، والأثر، والمعالجة، والمسؤول |
| سياسة أو إجراء | الغرض، ثم النطاق، ثم التعريفات، ثم الأحكام أو الخطوات، ثم الأدوار والمسؤوليات، ثم المراجعة والاعتماد | لا قسم مخاطر عادةً؛ الضوابط داخل الأحكام |
| تقرير أداء أو متابعة | الملخص، ثم الإنجاز مقابل المستهدف، ثم الانحرافات وأسبابها، ثم الإجراءات التصحيحية | المخاطر الناشئة فقط، مع ما يلزم من قرار |
| نظرية تغيير | تُبنى على مهارتها الخاصة حين تتوفر | الافتراضات والمخاطر جزء من منطق التغيير نفسه |
| مقترح لجهة مانحة | الملخص، ثم الاحتياج، ثم الحل، ثم منطق الأثر، ثم الخطة والميزانية، ثم القياس، ثم قدرة الجهة | فقرة تبيّن المخاطر الرئيسة ومعالجتها، دون تهويل |
| خطاب رسمي | صيغ المراسلة الرسمية، ثم الغرض في الفقرة الأولى، ثم المطلوب، ثم الختام الرسمي. لا محتويات ولا ملخص | لا يُعرض عادةً |
| عرض تقديمي | شريحة القرار أو الرسالة الرئيسة أولًا، ثم الحجة في شرائح قليلة، ثم المطلوب | شريحة واحدة إن لزم |
| مخرج إبداعي (اسم، شعار نصي، مفهوم) | لا بنية افتراضية؛ البدائل مع مبرر قصير لكل بديل | لا يُعرض |

## قواعد مشتركة

- كل توصية: ماذا، ومن، ومتى، متى ما كانت متاحة؛ وإلا فبين معقوفين.
- الجدول لما فيه مقارنة أو مصفوفة أو مسؤوليات. ما سوى ذلك فقرات.
- طول الأقسام بحسب وزنها عند القارئ، لا بالتساوي.
- الملاحق لما يحتاجه المختص ولا يحتاجه صاحب القرار.
