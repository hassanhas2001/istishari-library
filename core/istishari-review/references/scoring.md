# مرتكزات التقويم

الدرجة الرقمية بلا مرتكزات تتفاوت من مراجعة إلى أخرى. لذلك تُقيَّد كل درجة بالوصف أدناه، وتتبع الملاحظات لا العكس.

## المرتكزات العامة

| الدرجة | المعنى |
| --- | --- |
| ٩–١٠ | لا ملاحظة مانعة ولا ملاحظة جودة ذات وزن في هذا المحور |
| ٧–٨ | ملاحظات جودة قليلة، ولا مانع |
| ٥–٦ | ملاحظات جودة كثيرة تضعف المخرج، أو ملاحظة مانعة واحدة سهلة الإصلاح |
| ٣–٤ | ملاحظة مانعة جوهرية، أو عدة ملاحظات مانعة |
| ١–٢ | المحور غائب أو يحتاج إلى إعادة بناء |

## قيود ملزمة

- محور فيه ملاحظة مانعة لا تتجاوز درجته ٦.
- معلومة مختلقة واحدة تجعل محور الأمانة ٤ على الأكثر.
- محور معايير القبول = (عدد المعايير المتحققة ÷ عددها) × ١٠، مقربًا.
- إذا لم يُفحص محور لنقص المعطيات، فاكتب «لم يُفحص» بدل الدرجة.

## ربط التقويم بالحكم الختامي

| الحكم | الشرط |
| --- | --- |
| يُرفع كما هو | لا ملاحظة مانعة، وكل المحاور ٧ فأعلى |
| يُرفع بعد التعديلات | ملاحظات مانعة قابلة للإصلاح دون تغيير البنية، أو محور واحد دون ٧ |
| يُعاد بناؤه | محور ملاءمة القارئ أو التسلسل ٤ فأدنى، أو ملاحظات مانعة تمس البنية |

لا تحسب متوسطًا عامًا؛ المتوسط يخفي المحور الضعيف.
