# صيغة المواصفات

ملف JSON واحد بترميز UTF-8.

## الحقول العامة

| الحقل | إلزامي | المعنى |
| --- | --- | --- |
| `template` | نعم | `kpi` أو `bars` أو `steps` أو `chain` أو `compare` |
| `title` | نعم | العنوان، ويقول الرسالة |
| `subtitle` | لا | سطر تحت العنوان (الفترة، النطاق) |
| `items` | نعم | العناصر، وصيغتها بحسب القالب أدناه |
| `source` | لا | المصدر، يظهر أسفل الصورة |
| `digits` | لا | `keep` (الافتراضي) أو `arabic` |
| `width` | لا | العرض بالبكسل، والافتراضي 1200 (يُضاعف في PNG) |
| `theme` | لا | `primary` و`accent` و`text` و`muted` و`bg` و`panel` بصيغة `#RRGGBB`، و`font` اسم خط CSS |

## العناصر بحسب القالب

- `kpi` و`bars`: `{"label": "...", "value": 1200, "unit": "٪", "note": "..."}`. و`value` رقم أو نص أو `null`.
- `steps` و`chain`: `{"label": "...", "note": "..."}`، و`value` و`unit` اختياريان.
- `compare`: `{"label": "نقاط القوة", "points": ["...", "..."]}`. عنصران يُعرضان جنبًا إلى جنب، وأربعة في شبكة ٢×٢ (القوة والضعف في الصف الأول، والفرص والتهديدات في الثاني).

ترتيب العناصر في الملف هو ترتيب القراءة: الأول على اليمين، أو في الأعلى. ورتّب `bars` تنازليًا إلا إذا كان للفئات ترتيب طبيعي.

## أمثلة

بطاقات مؤشرات:

```json
{
  "template": "kpi",
  "title": "١٢٠٠ متدرب في النصف الأول من ٢٠٢٦",
  "digits": "arabic",
  "source": "تقارير البرنامج",
  "items": [
    {"label": "المستفيدون", "value": 1200, "note": "متدرب أكملوا التسجيل"},
    {"label": "نسبة الإكمال", "value": 85, "unit": "٪"},
    {"label": "الشركاء", "value": 14},
    {"label": "ساعات التدريب", "value": null}
  ]
}
```

سلسلة النتائج:

```json
{
  "template": "chain",
  "title": "سلسلة النتائج",
  "digits": "arabic",
  "items": [
    {"label": "الأنشطة", "note": "برامج تدريب وإرشاد"},
    {"label": "المخرجات", "value": 1200, "note": "متدرب مؤهل"},
    {"label": "النتائج", "value": 70, "unit": "٪", "note": "من الخريجين موظفون"},
    {"label": "الأثر", "note": "تحسن الدخل والاستقرار الوظيفي"}
  ]
}
```

بهوية الجهة:

```json
"theme": {"primary": "#0B5D4B", "accent": "#D4A72C", "font": "'Tajawal', sans-serif"}
```

## حدود معروفة

- الخط: بلا `--font` يُستعمل أول خط عربي متاح في جهاز القارئ، فقد يختلف المظهر بين الأجهزة. للنشر، ضمّن الخط أو سلّم PNG.
- `steps` الأفقي يتسع لخمس مراحل بنص قصير. ما زاد يتحول إلى عمودي تلقائيًا.
- الوزن العريض يُحاكى إذا ضُمّن ملف خط بوزن واحد.
