## الأحجام المقترحة

الحرف العربي يبدو أصغر من اللاتيني في الحجم الاسمي نفسه، لذلك تُرفع الأحجام قليلًا:

| العنصر | Word (نقطة) | PowerPoint 16:9 (نقطة) |
| --- | --- | --- |
| نص الفقرات | 12–14 | 18–24 |
| العنوان الفرعي | 14–16 | 24–28 |
| العنوان الرئيس | 18–22 | 32–40 |
| الحواشي والمصادر | 9–10 | 12–14 |

تباعد الأسطر في الفقرات بين 1.3 و1.5، لأن للحروف العربية امتدادات فوق السطر وتحته.

## تطبيق الاتجاه في الملفات المبنية برمجيًا

- **Word:** اتجاه الفقرة من اليمين إلى اليسار (`bidi`) في الأنماط نفسها لا في كل فقرة، واتجاه الجدول من اليمين، وتعيين الخط للنص المعقد (complex script) لا للنص اللاتيني فقط. بدون ذلك يظهر الخط العربي بالخط الافتراضي.
- **PowerPoint:** اتجاه الفقرة من اليمين (`rtl`) ومحاذاة لليمين في كل مربع نص، وتعيين لغة النص عربية.
- **HTML:** `<html dir="rtl" lang="ar">`، وقائمة خطوط تبدأ بالخط المختار ثم بديل نظامي.

## حساب التباين

```python
def lum(hex_):
    c = [int(hex_[i:i+2], 16) / 255 for i in (1, 3, 5)]
    c = [x / 12.92 if x <= 0.03928 else ((x + 0.055) / 1.055) ** 2.4 for x in c]
    return 0.2126 * c[0] + 0.7152 * c[1] + 0.0722 * c[2]

def contrast(a, b):
    la, lb = sorted([lum(a), lum(b)], reverse=True)
    return (la + 0.05) / (lb + 0.05)

print(round(contrast("#1F3A5F", "#FFFFFF"), 2))  # يجب ألا يقل عن 4.5 لنص الفقرات
```

الحد الأدنى 4.5:1 لنص الفقرات، و3:1 للنص الكبير (العناوين من 18 نقطة فأكثر، أو 14 نقطة عريضة).
